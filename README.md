صندوق من 1.0.0 — پروژه Android مستقل
نام بسته: com.sandoogh.man
حداقل Android: 6.0 (API 23)
هدف: Android 15 (API 35)

این پروژه یک اپ واقعی Android با Activity، Manifest، منابع UI و ذخیره محلی اولیه است.
برای ساخت APK روی سیستم دارای Android Studio/Gradle:
1. پروژه را در Android Studio باز کنید.
2. Gradle Sync را بزنید.
3. Build > Build APK(s).
